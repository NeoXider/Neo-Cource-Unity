# Пример: проверка наличия объекта на сцене

Создайте объект `Player` на сцене и нажмите кнопку проверки:

```check
rules:
  - object_exists: "Player"
```

> Это стабильная проверка (`object_exists`). Она считает успехом, если в сцене найден объект с именем `Player`. Кнопка «Проверить» подставляется автоматически.
