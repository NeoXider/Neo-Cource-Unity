# Таблицы

Таблица — это строка-шапка, строка-разделитель и строки с данными. Колонки разделяет символ `|`.

| Тип | Что хранит | Пример |
| --- | --- | --- |
| `int` | целое число | `int coins = 10;` |
| `float` | дробное число | `float speed = 2.5f;` |
| `bool` | да или нет | `bool isDead = false;` |
| `string` | текст | `string name = "Slime";` |

---

## Выравнивание колонок

Двоеточие в строке-разделителе задаёт выравнивание: `:---` — влево, `:---:` — по центру, `---:` — вправо.

| Враг | Здоровье | Награда |
| :--- | :---: | ---: |
| Слизень | 3 | 1 |
| **Бронированный** | 6 | 3 |
| Делитель | 4 | 2 |

---

## Длинный текст в ячейке

Таблица занимает ширину окна, а длинный текст в ячейке переносится на следующую строку. Сузьте окно и проверьте: горизонтальной прокрутки не появится.

| Метод | Когда вызывается | Для чего используем |
| --- | --- | --- |
| `Start()` | один раз, перед первым кадром, когда объект уже появился на сцене | задать начальные значения и найти нужные объекты |
| `Update()` | каждый кадр, пока объект включён | читать нажатия и двигать объект |
| `OnTriggerEnter2D()` | в момент, когда в триггер вошёл другой коллайдер | засчитать попадание или подобрать бонус |

---

## Строка без разделителя — не таблица

Текст с символом | без строки-разделителя остаётся обычным абзацем.

a | b | c
