## О проекте

`AlgoNeoCourse` — это Unity Editor пакет для интерактивных учебных курсов прямо внутри редактора.

Пакет умеет:

- показывать уроки из Markdown;
- переключать слайды в окне курса;
- выполнять `check`-проверки;
- запускать квизы `single`, `multiple`, `truefalse`;
- сохранять локальный прогресс в JSON;
- работать с изображениями и видео (`.mp4`).

Репозиторий: [Neo-Cource-Unity](https://github.com/NeoXider/Neo-Cource-Unity)

Главная спецификация уроков: `Assets/_AlgoNeoCourse/Docs/CourseMarkdownSpec.md`

## Установка

Рекомендуемый способ: через UPM по Git URL.

1. Откройте `Window -> Package Manager`.
2. Нажмите `+ -> Add package from git URL...`.
3. Укажите:

```text
https://github.com/NeoXider/Neo-Cource-Unity.git?path=Assets/_AlgoNeoCourse
```

Альтернатива через `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.neoxider.algoneocourse": "https://github.com/NeoXider/Neo-Cource-Unity.git?path=Assets/_AlgoNeoCourse"
  }
}
```

## Зависимости

Единственная внешняя зависимость:

```text
com.unity.nuget.newtonsoft-json
```

`MarkdownRenderer` уже встроен в пакет и отдельно ставить его не нужно.

## Быстрый старт

1. Откройте `Tools -> AlgoNeoCourse -> Settings -> Open Course Settings`.
2. Укажите `repositoryBaseUrl`, если нужен свой источник курса.
3. Выберите JSON курса:
   - `Course1`
   - `Course2`
   - `Custom`
4. Нажмите `Загрузить список уроков`.
5. Скачайте нужные уроки.
6. Откройте `Tools -> AlgoNeoCourse -> Open Course Window`.

## Окно курса

В окне курса доступны:

- выпадающий список уроков с `%` прохождения и галочками `✓` у завершённых;
- полоса общего прогресса курса;
- кнопка `▶ Продолжить` (возврат к сохранённой позиции);
- навигация по слайдам (только кнопки `<` / `>` и стрелки; `unity://slide`-ссылки удалены в `1.6.0`);
- перезагрузка текущего урока;
- открытие текущего `.md` файла;
- сброс локального прогресса;
- меню `Docs` с примерами из `Docs/Examples`.

Горячие клавиши:

- `Left` / `Right` — предыдущий и следующий слайд;
- `R` — перезагрузить урок;
- `O` — показать текущий `.md` файл.

## Локальное сохранение

Плагин автоматически сохраняет:

- последний открытый урок;
- текущий слайд;
- состояние квизов по всем урокам.

Уже пройденные квизы не нужно проходить заново после перезапуска Unity.

Сохранения строго per-project: путь вне текущего проекта игнорируется и не перезаписывает
локальную сессию. Личные `Progress/`, `QuizState/`, `VideoCache/` не коммитятся (в `.gitignore`).

Ручной перенос: `Tools -> AlgoNeoCourse -> Settings -> Progress -> Export/Import JSON...`.

Проверка уроков: `Tools -> AlgoNeoCourse -> Settings -> Validate Lessons` — дубли `id:`, пустые `answers`,
неизвестные `kind`, битые медиа и `unity://`-ссылки списком с переходом к файлу.

Основные пользовательские папки:

- `Assets/_AlgoNeoCourse/Downloaded`
- `Assets/_AlgoNeoCourse/Progress`
- `Assets/_AlgoNeoCourse/VideoCache`

Это сделано специально, чтобы локальные данные оставались в `Assets`, а не внутри read-only UPM-пакета.

## Настройки

Основные окна настроек:

- `Tools -> AlgoNeoCourse -> Settings -> Open Course Settings`
- `Tools -> AlgoNeoCourse -> Settings -> Open Quiz Settings`
- `Tools -> AlgoNeoCourse -> Settings -> Open Validation Settings`

Что важно в `Course Settings`:

- `repositoryBaseUrl`
- выбор курса `Course1` / `Course2` / `Custom`
- папка загрузки уроков
- список уроков по модулям: отметить, скачать один модуль или всё сразу

Что важно в `Quiz Settings`:

- `maxAttemptsPerQuestion`
- `randomizeAnswersOnCourseOpen`
- `guardSlideNavigation`
- `stateJsonFolder`

## Как устроены курсы

Каждый курс описывается отдельным JSON-файлом:

- `course1.json`
- `course2.json`
- или любой другой `courseN.json` для режима `Custom`

Каждый урок — это отдельный `.md` файл, указанный в поле `file`.

Пример записи урока:

```json
{ "id": "l2m2y1", "title": "Основы синтаксиса C#", "file": "lessons2/m2/y1.md" }
```

Разделитель слайдов:

```md
---
```

## Поддерживаемые возможности Markdown

Поддерживаются:

- обычные заголовки и текст;
- fenced code blocks (подсветка C# и Python);
- таблицы (pipe tables: строка-шапка и строка-разделитель `| --- | --- |`);
- `quiz`;
- `check`-блоки (кнопка «Проверить» подставляется автоматически);
- ссылки `unity://open`;
- изображения и видео.

Поддерживаемые пути к медиа:

- `http://` и `https://`;
- относительные пути от текущего `.md`;
- `Assets/...`;
- `Packages/...`;
- поиск по имени файла.

## Примеры

Пример `check`:

````md
```check
rules:
  - object_exists: "Player"
  - component_exists:
      object: "Player"
      type: "Rigidbody"
  - filename: "PlayerController.cs"
  - contains: "public class PlayerController"
```
````

Пример `quiz`:

````md
```quiz
id: sc-hello
kind: single
text: Какой модификатор доступа делает поле приватным в C#?
answers:
  - text: private
    correct: true
  - text: public
  - text: protected
  - text: internal
```
````

## Видео и GIF

- для анимации используйте `.mp4` — оно проигрывается прямо в слайде;
- GIF как анимация не поддерживается: конвертация GIF -> MP4 и `ffmpeg` удалены в `1.7.0`.

## FAQ

### Относительные пути к медиа не работают

Проверьте, что путь задан относительно папки текущего `.md`.

### Горячие клавиши не работают

Кликните в тело окна курса, чтобы оно получило фокус. Переход вперёд может быть заблокирован незавершёнными квизами.

### GIF не анимируется

Это ожидаемо. Используйте `.mp4`: встроенная конвертация GIF удалена в `1.7.0`.

### Появляется сообщение про MarkdownRenderer

В актуальной версии пакет использует встроенный `MarkdownRenderer`; отдельная установка не требуется.

### Ошибка CS0619 про `AssetDatabase.GetAssetPath(int)` (Unity 6.3+)

В Unity 6.3 `int`-based `InstanceID` API стали ошибкой. Исправлено в `1.5.1`:
`MarkdownViewer.HandleDblClick` использует `EntityId` под `#if UNITY_6000_3_OR_NEWER`
с fallback на `int` для старых версий Unity. Других `GetAssetPath(int)` / `OnOpenAsset(int)`
использований в пакете нет.

### Ошибка CS0308 про `VideoPlayerElement.UxmlFactory` (Unity 6.6)

В Unity 6.6 legacy `UxmlFactory/UxmlTraits` удалены. Исправлено в `1.5.2`:
`VideoPlayerElement` использует `[UxmlElement]` под `#if UNITY_6000_0_OR_NEWER`
(работает на всех Unity 6.0–6.6), на старых Unity остаётся `UxmlFactory`.
С `1.8.0` встроенный рендерер — точная копия Neoxider Markdown Renderer и больше не патчится:
пункт меню `Dependencies -> Apply Embedded Markdown Fix` удалён.

### После перезагрузки Unity открывается не тот урок/слайд

Исправлено в `1.5.2`: восстановление сессии больше не затирает сохранённую
позицию промежуточным `ShowSlide(0)` (подавление записи на время restore +
одна финальная запись), пути нормализуются к `/`, повторный restore после
рекомпиляции пропускается, устаревший `shuffledOrder` после правки `.md`
пересоздаётся вместо падения.

### Что нового в 1.7.0

- Практические задания: вместо сырого YAML блока `check` — карточка «что проверит Unity» с понятными пунктами. После «Проверить» каждый пункт получает ✓ или ✕ и подсказку, что не так; счётчик «проверки N/M» обновляется сразу.
- Анимации: слайд въезжает со стороны движения, кнопки плавно подсвечиваются и «нажимаются», пункты проверки отмечаются по очереди.
- При смене слайда содержимое прокручивается в начало.
- Единая тёмная тема слайдов: заголовки, цитаты, блоки кода. Исправлены стили, которые Unity молча отбрасывал (у заголовков не было размера; `gap`, `box-shadow`, `border-style`).
- `Course Settings`: уроки сгруппированы по модулям — галочка на весь модуль, счётчики «отмечено / скачано», кнопка «Скачать» у каждого модуля, поиск. Список уроков подгружается сам при смене курса (пресет, ссылка или имя JSON).
- Повторная загрузка списка сохраняет расставленные галочки.
- Кнопки проверки появляются и в уроках с Windows-переводами строк (`\r\n`).
- Удалены `ffmpeg`, конвертация GIF -> MP4, кэш видео и их настройки.
- Меню `Tools/AlgoNeoCourse` упрощено: наверху один пункт `Open Course Window` (горячая клавиша `Ctrl+Alt+L`), остальное — в `Tools -> AlgoNeoCourse -> Settings`.

Проверки заданий (`check`) стали строже и точнее:

- находят выключенные объекты (например, скрытую панель Game Over) и принимают путь в иерархии (`Canvas/WallText`);
- блок без правил, с опечаткой в ключе или с неизвестным правилом теперь не проходит (раньше молча засчитывался);
- работает `scene_name`; `component_exists` только с `type` означает «у любого объекта сцены»;
- `contains` учитывает регистр; несколько `filename` в одном блоке — каждый `contains` относится к ближайшему `filename` выше;
- имя типа компонента точное: проверка на `CircleCollider2D` больше не проходит с `BoxCollider2D`.

Исправления:

- прогресс больше не теряется при другом регистре пути, переносе проекта и импорте на другой ПК (ключи — относительные пути, старые записи переносятся автоматически, исходный файл сохраняется рядом как резервная копия);
- сохранённый слайд больше не применяется к чужому уроку, если прежний урок удалён или переименован;
- выпадающий список уроков следует за «Продолжить» и восстановлением сессии; «Продолжить» неактивна, когда вы уже в дальней точке;
- `>` выключена на последнем слайде и подсказывает, если её блокирует неотвеченный квиз;
- неверный ответ в квизе подсвечивается, пока остались попытки;
- окно не забирает фокус после перекомпиляции, `Ctrl+R` / `Ctrl+O` не срабатывают как горячие клавиши курса;
- названия уроков в списке не обрезаются по 25 символам всей строки `l2 / m2 / …`;
- счётчик «проверки N/M» работает для уроков с Windows-переводами строк.

### Что нового в 1.8.0

- Таблицы в уроках: pipe-таблицы (строка-шапка и строка-разделитель `| --- | --- |`) показываются сеткой — с шапкой, полосатыми строками и выравниванием колонок (`:---`, `:---:`, `---:`). Пример — `Assets/_AlgoNeoCourse/Docs/Examples/tables.md` (в окне курса: меню `Docs` → `tables`).
- Встроенный рендерер Markdown обновлён до Neoxider Markdown Renderer 1.3.0. Папка `Plugins/markdownrenderer` — точная копия апстрима и обновляется заменой папки; стили квизов и карточек заданий переехали в `Editor/Styles/AlgoNeoQuiz.uss`.
- Окно курса никогда не показывает горизонтальную прокрутку: текст, код и таблицы подстраиваются под ширину окна. Исправлен случай, когда на высоком слайде список в цитате или последняя строка кода уезжали за правый край.
- У слайда одна область прокрутки вместо двух вложенных; анимация въезда двигает всю карточку слайда.
- Подсветка кода: палитра VS Code Dark+ для C#, добавлена подсветка Python.
- Блок кода внутри пункта списка больше не пропадает; нумерованный список начинается с числа, которое написал автор.

- Удалён пункт меню `Dependencies -> Apply Embedded Markdown Fix`.
